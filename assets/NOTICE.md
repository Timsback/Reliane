# Ressources Dofus

L'application utilise, pour cette installation personnelle :

- `dofus-emeraude.png`, récupéré depuis `https://static.ankama.com/dofus/www/game/items/200/23002.png`, ou depuis le miroir DofusDB `https://api.dofusdb.fr/img/items/23002.png` si le CDN ne répond pas avec une image valide ;
- les 31 portraits de `classes/` et les petites icônes de `game-icons/`, copiés de l'installation Dosoft locale à la demande de l'utilisateur ;
- des déclinaisons de taille de l'icône Émeraude pour l'icône Windows et le favicon.

Ces images représentent des éléments Dofus. Elles ne sont pas des créations originales de Reliane. Les droits restent à leurs titulaires, notamment Ankama. L'application est indépendante et ne bénéficie d'aucune affiliation officielle.

**Les images de jeu et leurs déclinaisons sont exclues du dépôt GitHub public.** `fetch_assets.py` permet leur récupération séparée sur l'ordinateur de l'utilisateur. Sans portraits, l'application affiche des symboles de secours dessinés dans le code.

Aucune image générée par IA n'est utilisée dans la version finale.
